# Earthquake Damage Prediction

## Project Overview
This project focuses on predicting the level of building damage caused by earthquakes using machine learning techniques. It analyzes structural, geographical, and building-related features to classify buildings into different damage grades and support better understanding of earthquake impact.

## Objectives
- Understand and analyze earthquake-related building data.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Identify important features influencing building damage.
- Train and compare multiple machine learning classification models.
- Evaluate model performance using appropriate classification metrics.
- Predict building damage grades based on input features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Approach
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Feature Selection
- Classification Modeling
- Model Evaluation

## Target Variable
`damage_grade`

The target variable represents three levels of earthquake-induced building damage:

- Grade 1 – Low Damage
- Grade 2 – Medium Damage
- Grade 3 – Almost Complete Destruction

## Model Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Classification Report

## Project Structure
- `Earthquake_Damage_Prediction.ipynb` – Complete Jupyter Notebook containing data preprocessing, exploratory analysis, model development, and evaluation.
- `README.md` – Project documentation.

## Conclusion
This project demonstrates the application of machine learning classification techniques to predict earthquake-induced building damage levels. By analyzing structural and geographical features, the project aims to identify damage patterns and support data-driven understanding of building vulnerability during earthquakes.
